# 掼蛋规则与本房间方言

本实现采用江苏常见的四人、两副牌、对家合作升级玩法。各地赛事在过 A、首副领出、贡牌同点分配及还牌例外上存在差异；以下约定是本项目的权威规则。服务端执行相同的纯状态机，客户端不能自行裁定出牌、名次或交换。

## 牌、座次与级数

- 两副完整牌共 108 张，每座 27 张。每张实体牌的 ID 包含牌副、花色和点数；两张同点同花色牌仍是不同牌。
- UI 的 1、3 座同队，2、4 座同队；代码座位为 `0..3`，同队判定为 `seat % 2`，对家为 `(seat + 2) % 4`。
- 代码出牌方向固定为 `0 → 1 → 2 → 3 → 0`，即座号增加的一侧称“下家”。桌面方向应按此约定绘制。首副固定 1 座领出；这是在线房间的简化约定，不实施现实比赛的翻明牌定首家。
- 两队级数分别从 2 开始，保存到本场结束。下一副使用上一副胜方升级后的级数作为级牌，两队所有玩家使用同一级牌规则。
- 单张及同点牌组的大小为：大王 > 小王 > 级牌 > A > K > … > 2；自然点序中的级牌被提到 A 上方。
- 两张红桃级牌是逢人配，可替代除大小王外的任意普通牌点、花色。单独打出时仍是当前级牌，不能声明为别的单牌。

## 允许牌型与比较

| 牌型 | 固定张数 / 约定 |
| --- | --- |
| 单张、对子、三张 | 同点比较；同点不同花色不能互压 |
| 三带二 | 三张同点加另一点的一对，比较三张部分；自然同点王对可作附件 |
| 顺子 | 恰好 5 张连续普通点数；允许 A2345，最大 10JQKA |
| 三连对 | 恰好 3 对连续点数；允许 AA2233，最大 QQKKAA |
| 钢板 / 二连三 | 恰好 2 组三张连续点数；允许 AAA222，最大 KKKAAA |
| 同点炸弹 | 4 至 10 张同点牌，百搭只补普通点数 |
| 同花顺 | 同花色的 5 张顺子，可由逢人配补牌或花色 |
| 四王炸 | 恰好两张小王、两张大王，不能以百搭补王 |

顺子、三连对、钢板使用自然点序，级牌在这些牌型中不升到 A 上方。A 仅可位于合法的最低端或最高端，不允许 K-A-2 环绕。普通牌型须种类、张数相同才可比较；三带二比较三张部分。炸弹及同花顺的优先顺序为：

`四王炸 > 10张炸 > 9张炸 > … > 6张炸 > 同花顺 > 5张炸 > 4张炸 > 普通牌型`

同张数炸弹比较牌点，同花顺比较顺子的最高自然点。王牌不进入普通顺子、连对、钢板，也不能组成普通同点炸弹。

如果所选百搭牌具有多种解释，领出时使用确定性的最高优先解释；跟牌时会枚举可行解释并选择能压过前手的最高优先解释，避免把能接三连对的牌误判成钢板。返回的牌型包含百搭替代说明。当前 UI 不提供主动选择较弱解释的操作。

## 出牌、不出、接风与名次

1. 只能在自己出牌回合提交自己持有的、不重复的实体牌。领出不能“不出”；跟牌必须压过本圈最近一次出牌，或选择“不出”。
2. 每次有人成功压牌，之前的“不出”记录清空。先前不出过的人，在有人重新压牌后仍可参与。
3. 已出完的人立即得到当前名次，并从后续轮转跳过。其他仍有牌的人均对本圈最后出牌者表示不出后，结束一圈。
4. 最后出牌者仍有手牌，由他重新领出；他已出完且对家仍在，则由对家接风。对家也已出完时，从该最后出牌者的下家方向寻找第一位仍有牌的人领出。接风后是新的领出，可出更小的牌或不同牌型。
5. 第三个人出完后，剩余一人自动记为第四名，本副结束。最后一人的余牌保留在其手牌区域，不伪造出牌或销毁牌张。即使前两名已是同队，另外两人的三、四游仍需确定。

## 升级与过 A

头游所在队获胜，按对家名次获得名义升级数：二游升 3 级、三游升 2 级、末游升 1 级。只有胜方升级，负方级数保留；升级最多到 A，不能跳过 A 直接获整场胜利。

本房间采用“头游、对家不能末游”的过 A 规则：胜方自己的级数已经是 A、本副实际打 A，并且对家为二游或三游，才赢得整场。刚从 K 升到 A 不算过 A；己方虽停在 A、但本副使用对方较低级数时赢牌，也不算过 A。两队均到 A 时，任何一方满足上述名次即可获整场胜利。

本项目不采用“连续三次不过 A 退回 2”的额外惩罚；在 A 获头、末游可以继续打 A。整场完成后不能以该结果接续发下一副，需开始一场新比赛。

## 下一副的进贡、还牌与抗贡

从第二副开始，在所有人各得 27 张牌后处理上一副的排名。该阶段允许所有尚未选择的合资格玩家提交选择，不要求贡牌 / 还牌选择按出牌方向依次进行；`turn` 只提示下一位等待选择的人，出牌阶段才严格逐座轮转。

### 贡牌资格与还牌限制

- 进贡者必须从自己的手牌中，选出**排除红桃级牌后的最大牌**。按当前级牌大小比较；若有多个同强度的实体牌，可任选一个。
- 还牌者有非级牌的 2 至 10 时，必须从这些牌中选择。不得用低点数的级牌绕过限制。
- 若没有上述普通小牌，则还最小的非红桃级牌，同强度可任选。若某个状态只剩红桃级牌，则仅能从现有牌中选最小牌；正常 27 张还牌阶段不会出现此种手牌。
- 还牌只能从受贡者**交换前自己的手牌**选择；不能立即把刚收到的贡牌退回。

### 单贡

上一副的头、二游不是同队时，上一副末游向头游进贡一张，头游向此末游还一张。正常交换后，由此进贡者领出。

### 双贡

上一副头、二游同队时，三、四游各进贡一张。较大的贡牌给原头游，另一张给原二游，两位受贡者各向自己的进贡者还牌。

若两张贡牌等大，按与出牌轮转相反的方向进贡：**原头游的下家给头游，另一名进贡者给二游**。例如原头游为 1 座、二游为 3 座，则 2 座给 1 座、4 座给 3 座；原头游为 3 座时则反过来。这一配对不受上一副三、四游排序或本次提交先后影响。

正常双贡完成后，给原头游进贡的人领出。因此不等大时大贡牌的贡献者先出，等大时原头游的下家先出。

### 抗贡

若所有应进贡者合计持有两张大王，则本副自动整体抗贡：单贡时末游一人必须有两张；双贡时可以一人持两张，也可以两人各持一张。合计大王检查只看应进贡者，不能把单贡者对家手里的大王算进来。

抗贡跳过所有贡牌与还牌，所有人仍为 27 张，由上一副头游领出；不触发下面的双贡弃牌。

### 原子交换与公开范围

贡牌选定后，贡牌与配对公开；个人选择不能再次提交或修改。双贡两人的贡牌未选齐，仍停留在进贡阶段；全部选齐才进入还牌阶段。

所有受贡者完成还牌选择后，服务端一次性执行所有对应交换。此前手牌区域保持原状，不会出现一方先拿到贡牌、另一方尚未还牌的半交换状态。待完成的还牌选择不公开，交换完成后牌张、配对写入公开记录。记录只引用实体牌，不是额外的牌区域。

## 房规：双贡后可弃一张（默认开启）

这是本房间可选的额外规则，独立实现于 `shared/house-rule.ts`，不是标准进贡规则的一部分。房主可在开局前关闭；选择随本场下一副保留。

- **仅在未抗贡的双贡、全部标准贡牌还牌原子交换完成之后**，才进入弃牌选择阶段。
- 两名进贡者各有一次选择机会：从交换后的自己手牌中弃任意一张，或明确跳过。
- 两人可以任意先后操作。弃牌或跳过都消耗本人的这次机会，不能撤回、二次弃牌或再次跳过。
- 弃掉的牌进入公开的 `removed` 区域并记录，手牌变成 26 张；跳过者仍为 27 张。
- 必须等待两人都选择完成才开始出牌。领出者仍按标准双贡配对确定；房规不改变先手。
- 单贡、抗贡、未完成还牌、房规关闭以及出牌已经开始时，一律不能执行双贡弃牌。

## 状态与验证边界

每个合法状态中，`hands`、`played` 和 `removed` 三类牌区域合计恰好 108 张，实体 ID 不重不漏。当前牌圈、历史记录及贡还牌记录只是引用，不再次计牌。新副重新生成两副完整牌并重置这些区域。

`applyGuandan` 在拒绝错误回合、错误阶段、重复提交、无效牌型、越权牌张等操作时抛出错误，不修改传入状态。成功转换也返回新状态；房间服务器在成功后才增加版本并广播，私牌可见性由服务器快照层控制。

验证包含固定实牌布局的单贡 / 双贡 / 抗贡、四种朝向的同贡映射、部分阶段重放、活对家与已完对家的接风、升级及过 A 失败重试、房规弃牌和跳过，以及多个种子下连续三副对局中**每一步**的 108 张身份守恒和输入不变性。参见 `tests/guandan.test.ts` 与 `tests/guandan-combinations.test.ts`。

## 参考与差异说明

规则核对使用公开比赛细则，而非宣称某一赛事的完整复刻：

- [东南大学：扑克牌（掼蛋）比赛规则（两副牌）](https://ddgh.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)：牌型、炸弹顺序、接风、级数与同贡先手。
- [中国石油大学：机关职工掼牌（掼蛋）交流活动比赛规则](https://www.cup.edu.cn/jiguan/docs/2024-03/a37a68b7f82c405f94a214c2becf7cc3.pdf)：头游且对家非末游的过 A 条件、双贡等大时原头游下家先出。该赛事的三次不过 A 回 2 惩罚，本项目明确不采用。

线下赛事还可能采用翻明牌首发、时间 / 副数限制、裁判罚分、不同低 A 钢板规定及不同双贡同点协商方式。本房间不实现这些赛事管理制度；所有争议以本文件的明确在线约定为准。
