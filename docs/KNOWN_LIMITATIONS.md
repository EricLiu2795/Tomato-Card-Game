# 已知限制与未验证范围

- 这是朋友邀请房 MVP，无账号、机器人、观战、匹配、聊天文本、踢人/让座、托管、出牌倒计时、主机转让或中途补位。断线玩家需使用原浏览器 Cookie 返回；长时间离开会让当前牌局等待。可另建房间继续。
- 斗地主显示每局积分，没有跨房间排行榜。掼蛋级数在本房间多副之间保存，成功过 A 后可新开一场。
- 掼蛋方言已经完整写入 GUANDAN_RULES.md；本实现不是所有赛事规则的通用切换器。无 UI 手动指定逢人配解释：领出按确定顺序，跟牌按能压过上一手的合法解释自动选择。
- 移动布局以 Chromium 视口测试；没有实体 iPhone/iPad、真实 Mobile Safari 或 Android Chrome 的人工设备认证。27 张牌通过可滚动手牌区逐张触选；没有拖动多选或智能提示整手出牌。
- 浏览器中文 TTS 依赖操作系统可用语音。自动化测试检查用户启用后的播放调用和所有客户端事件，不代表听觉音质或实体扬声器输出已经验证。音频会受移动系统静音和浏览器自动播放策略影响。
- 互动事件是实时短暂效果，不在重连后补播；游戏状态与已接受命令回执会恢复。重试已接受互动命令不会再次广播。
- 已实现 Durable Object hibernation 接口；本地 Wrangler 验证不能替代 Cloudflare 生产环境的真实休眠/唤醒、全球网络和平台故障注入。没有执行生产部署、负载测试、外部渗透测试或成本实测。
- 本地开发端口和 Wrangler 管理/调试接口仅供可信本机使用。不要把开发进程当作公网生产服务。
- 房间最近公开历史有限（服务端 200 条，快照 100 条），不是完整可导出的整场回放。每房间接受命令上限 100,000；达到后需新建房间。空房默认 24 小时过期。
- 中文为默认界面，协议/声音注册表可扩展；尚未提供英文翻译和完整语言切换功能。

本文件只描述实际限制；具体执行过的测试、截图和结果见 TEST_RESULTS.md。若测试发现未修复问题，会在该文件注明重现方法。
