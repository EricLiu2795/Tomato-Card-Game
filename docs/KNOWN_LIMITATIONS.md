# 已知限制与未验证范围

- 好友房无账号、观战、匹配、聊天文本、踢人/让座、托管、出牌倒计时、主机转让或中途补位。断线玩家需使用原浏览器 Cookie 返回；长时间离开会让当前牌局等待。可另建房间继续。
- 大厅提供掼蛋与斗地主单人练习，电脑使用自己的手牌、公开牌桌与剩余张数作出启发式决策，不是高水平竞技 AI；电脑不能加入在线好友房。练习保留当前浏览器中最近一个存档，刷新或回大厅后可继续，不支持跨设备同步。清除站点数据会删除存档，存储不可用时页面会提示。悔棋只回退最近一次自己的操作（包括随后电脑的回复），不能连续回退多步；新开一局后清除悔棋点。
- 「提示」按牌型模板生成有限数量的合法推荐，再按组合保留、出牌张数及对手剩余牌排序，可反复点击换一手。它不是穷举或最优策略；没有推荐不代表不存在合法出牌。最终出牌仍由原规则引擎验证。
- 斗地主显示每局积分，没有跨房间排行榜。掼蛋级数在本房间多副之间保存，成功过 A 后可新开一场。
- 掼蛋方言已经完整写入 GUANDAN_RULES.md；本实现不是所有赛事规则的通用切换器。无 UI 手动指定逢人配解释：领出按确定顺序，跟牌按能压过上一手的合法解释自动选择。
- 移动布局以 Chromium 视口测试；没有实体 iPhone/iPad、真实 Mobile Safari 或 Android Chrome 的人工设备认证。27 张牌通过可滚动手牌区逐张触选；鼠标/触控笔支持拖动连选，触屏保留原生滑动滚动与单点选牌，尚不支持触屏拖动多选。
- 手机主操作栏固定在底部，节奏与悔棋收进「更多设置」。390×844 与 844×390 下，初始 27 张掼蛋牌和 20 张地主牌均可在操作栏上方完整显示。其他尺寸、放大字体或展开设置后仍可能需要滚动；测试覆盖卡牌聚焦/滚动后的操作栏避让，并不保证所有牌桌记录和说明同时出现在首屏。
- 中文短句使用随游戏发布的合成神经语音文件，音效由 Web Audio 实时合成；音频加载失败会回退为音乐提示。自动化测试检查文件可解码、授权播放路径与客户端事件，不代表实体扬声器输出已经验证。音频仍会受移动系统静音和浏览器自动播放策略影响。
- 现有 MP3 的来源记录为 `edge-tts` 调用 Microsoft Edge 在线服务。仓库尚未附上适用于这些输出的公开再分发许可依据；公开发布前需要核实该依据或替换为明确获授权的素材。此项是尚未核实的许可问题，不是侵权结论；关闭声音不会阻止静态文件被发布。
- 互动事件是实时短暂效果，不在重连后补播；游戏状态与已接受命令回执会恢复。重试已接受互动命令不会再次广播。
- 已实现 Durable Object hibernation 接口；本地 Wrangler 验证不能替代 Cloudflare 生产环境的真实休眠/唤醒、全球网络和平台故障注入。没有执行生产部署、负载测试、外部渗透测试或成本实测。
- 本地开发端口和 Wrangler 管理/调试接口仅供可信本机使用。不要把开发进程当作公网生产服务。
- 房间最近公开历史有限（服务端 200 条，快照 100 条），不是完整可导出的整场回放。每房间接受命令上限 100,000；达到后需新建房间。空房默认 24 小时过期。
- 中文为默认界面，协议/声音注册表可扩展；尚未提供英文翻译和完整语言切换功能。

本文件只描述实际限制；具体执行过的测试、截图和结果见 TEST_RESULTS.md。若测试发现未修复问题，会在该文件注明重现方法。
