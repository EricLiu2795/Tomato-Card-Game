## 完整浏览器对局

测试源码：`tests/e2e/games.spec.ts`、`players.ts`、`invite.spec.ts`。所有游戏动作通过正常 UI 发出；测试只读取各自 WebSocket 合法收到的手牌和公开状态，没有灌入牌序或提前结束游戏。

- **斗地主**：3 个独立上下文，63 次合法界面操作，1 局完整结束；农民获胜，积分 `[-6, 3, 3]` 且合计为 0。检查 220 份个性化快照。叫 3 分直接定地主、17→20 张手牌、底牌公开、页面刷新恢复、互动和结算均通过。
- **掼蛋**：4 个独立上下文，496 次合法界面操作，完成两副并进入第三副；胜队从 2 升至 5、再升至 8。通过正常单张和不出配合形成双下，第二副实际触发抗贡并完整继续，第三副实测两次进贡、两次还牌、一次弃任意牌、一次跳过。移除牌堆 1 张，弃牌者 26 张。提交一张贡牌后和提交一次弃牌后刷新，身份/手牌/选择标记均恢复，不能再次提交。
- 两局合计检查 **2,302 份快照**；私牌字段检查错误、页面异常和被服务器拒绝的 UI 操作均为 0。已公开的出牌/贡还牌/弃牌允许出现在公开历史，未公开的其他手牌不允许出现。
- **互动**：每个客户端收到相同的四个事件 ID（两条语音、一条表情、一次番茄）；气泡和动画可见。启用声音后 TTS 调用计数为斗地主 `[2,1,2]`、掼蛋 `[2,1,2,2]`，第二个客户端中途静音而保留文字。测试通过监听/替换 speechSynthesis 调用观察授权播放路径，**未验证真实扬声器输出**。
- **触屏**：390×844 和 844×390 两个视口，27 张牌全部通过真实触屏 tap 选中和取消；没有页面横向溢出。横屏可纵向滚动到手牌和操作区。
- **邀请链接**：2 个新上下文，第二位直接访问带房间码的 URL，表单自动填码，通过正常界面加入座位 1，身份与房主不同，未出现隐私或页面错误。

最终完整运行命令，以及开发期间使用过的分项诊断命令：

```bash
npm run test:e2e
npx playwright test tests/e2e/games.spec.ts --grep 'four independent'
npx playwright test tests/e2e/invite.spec.ts --output=artifacts/browser-invite
```

早期运行遇到开发文件热更新，以及测试观察器把已销毁页面的旧 socket 计入活动连接，导致测试失败或中断；已修正观察器并在源码稳定后重跑。测试没有把这些失败或中断计作通过。触屏用真正的 tap、桌面用卡片中心点击；避免在悬停位移动画边缘选择不稳定的测试坐标。最终浏览器截图与聚合结果保留在交付包。

## 规则与安全覆盖

- 78 项掼蛋测试：所有牌型、逢人配不得代王、炸弹排序、低 A 连续牌、歧义跟牌、接风、升级 3/2/1、过 A 和重试、单贡/双贡/同贡配对、整体抗贡、原子交换、房规弃牌/跳过、重复提交拒绝。四个确定种子各连续运行三副，逐步验证 108 张实体牌守恒。
- 84 项斗地主测试：全部支持牌型与非法牌型、飞机歧义、叫分/3 分即时确定/全不叫重新安全洗牌、轮次/不出/清圈、炸弹/春天计分、完整对局、54 张牌守恒、拒绝后输入状态不变。
- 21 项边界单元测试：逐座私牌白名单、叫分前隐藏底牌、交换前隐藏还牌、命令格式、伪造身份字段、Unicode 昵称、流式请求大小/5 秒超时、运行时卡牌守恒防线。
- 8 项真实网络测试：缺失/伪造/跨房间 Cookie，跨源 WebSocket，私牌/凭据不可见，无调试手牌路由，错误轮次/牌归属，旧版本拒绝，相同版本并发只接受一条，持久去重及改变内容复用 ID 拒绝，重连恢复，番茄冷却、无效事件和恶意消息洪泛限流。
- 2 项进程重启测试：独立端口 8791 和 inspector 9235、临时 SQLite 存储；共 4 次重启。恢复斗地主已出牌状态和去重回执；恢复掼蛋部分进贡、部分还牌、部分弃牌，证明未公开的还牌选择实际存储且最终正确交换，108 张牌仍守恒。
