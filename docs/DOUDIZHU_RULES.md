# 斗地主规则与实现约定

本项目使用三人、单副 54 张牌、叫分制斗地主。规则由服务端共享的纯函数执行；客户端不能自行改变手牌、回合或结算。

## 发牌与叫分

- 每人 17 张，另留 3 张底牌；叫分结束前底牌不应公开。
- 每人按顺序仅叫一次：不叫为 0，或叫高于当前最高分的 1 / 2 / 3 分。有人叫 3 分立即结束叫分；否则第三人叫完后最高叫分者为地主。
- 地主取得底牌，共 20 张，并首先领出。底牌此时公开，保留为展示引用；不代表额外的三张牌。
- 三家全不叫则重新洗牌、发牌，局号加一，首叫位轮换。第 `n` 局首叫位为 `(n - 1) % 3`（座位下标从 0 开始）。
- 初始发牌与全不叫后的重发均默认使用安全随机源。测试可向 `createDoudizhu` 的 `random` 选项及 `applyDoudizhu` 的第四个参数注入带种子的随机函数，使发牌与重发完全可复现；生产重发不从前一局状态推导有限种子。

## 牌型

牌点从小到大为 3、4、…、K、A、2、小王、大王；花色不参与大小比较。

| 牌型     | 要求                               | 示例       |
| -------- | ---------------------------------- | ---------- |
| 单张     | 任意一张                           | A          |
| 对子     | 同点数两张                         | 22         |
| 三张     | 同点数三张                         | 777        |
| 三带一   | 三张加一张其他点数                 | 777A       |
| 三带二   | 三张加一对其他点数                 | 777AA      |
| 顺子     | 至少 5 个连续点数，各一张          | 34567      |
| 连对     | 至少 3 个连续点数，各两张          | 334455     |
| 飞机     | 至少 2 个连续点数，各三张          | 333444     |
| 飞机带单 | 飞机加与三张组数相同数量的单张翅膀 | 33344478   |
| 飞机带对 | 飞机加与三张组数相同数量的对子翅膀 | 3334447788 |
| 四带二单 | 同点数四张加两张其他点数的牌       | 777789     |
| 四带二对 | 同点数四张加两对不同点数的牌       | 77778899   |
| 炸弹     | 同点数四张                         | 7777       |
| 王炸     | 小王与大王                         | 小王大王   |

顺子、连对和飞机主体都不能含 2 或王；A 只能作为最高点，不能回绕到 3。单张翅膀允许同点数（两张可以形成一对，三张相同也可作为三张单翼），也允许王；对子翅膀必须来自不同点数。所有翅膀不得使用飞机主体点数。同样，四带二单允许附带一对，四带二对要求附带两个不同点数的对子，不将另一组四张视作两对。

若某组牌可拆成多种飞机，领出时先按纯飞机判断，再从合法带翼拆分中选主体最大的。跟牌时优先匹配桌面牌型，例如 `333444555666` 可作为 `444555666` 带三张 `3`，压过较小的三组飞机带单。飞机主体点数自身的第四张不能作为翅膀。三带一、四带二和飞机带翼中的主体决定大小，翅膀点数不参与比较。

普通牌只能压过相同牌型、相同张数、相同连续组数的更小牌。炸弹可压任意普通牌，炸弹之间比较点数；王炸可压所有其他牌。四带二属于普通牌型，不是炸弹。

## 回合与胜利

- 按座位顺序轮流出牌，跟牌必须压过桌面当前牌型，也可以不出；领出者不能不出。
- 连续两家不出后清空桌面，由最后成功出牌者重新领出。中途有人压牌则清零连续不出记录；此前不出的玩家下轮仍可出牌。
- 地主先出完为地主胜；任意一位农民先出完为两位农民共同获胜，立即结束本局。
- 每次出牌校验当前阶段、座位、回合、牌的归属、牌 ID 唯一性、牌型和压牌关系。不合法操作抛错且完全不修改输入状态。已结束的牌局拒绝后续操作，不能重复结算。

## 计分

底分为地主的叫分。初始倍数为 1；每打出一次炸弹或王炸，倍数乘 2。地主胜且两位农民都未成功出过牌，称为春天，再乘 2；农民胜且地主整局只成功出过一手，称为反春天，再乘 2。不出不计为成功出牌。

令 `分值 = 底分 × 最终倍数`：地主胜得 `+2 × 分值`，两位农民各得 `-分值`；农民胜时地主得 `-2 × 分值`，两位农民各得 `+分值`。总分恒为 0。`scores` 保存本局分数变化，不是跨局累计分。

## API 与守恒

- `classifyDoudizhu(cards, previous?)` 返回标准化牌型或 `null`；可选桌面牌型用于消除飞机拆分歧义。
- `beatsDoudizhu(candidate, previous)` 比较两个标准化牌型。
- `createDoudizhu({ random?, handNumber? })` 创建叫分状态。
- `applyDoudizhu(state, seat, action, random?)` 返回新状态，或对非法动作抛错；可选随机函数仅用于三家不叫后的重发。

叫分时，`hands + bottom + played + removed` 恰好为唯一的 54 张牌；出牌开始后，`hands + played + removed` 恰好为唯一的 54 张牌。`bottom` 此后仅是已分入地主手牌的公开引用，不能重复计入守恒式；`trick` 和历史中的牌同样只是已出牌的引用。
