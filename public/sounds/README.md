# 番茄牌局声音资源

本目录的三个 WAV 提示音均为本项目原创、以数学波形合成的单声道 PCM 声音，不包含录音、采样、模仿声音或第三方素材，可随本项目自由使用和修改。当前运行时的表情、出牌、发牌、过牌、回合、炸弹、结算和番茄互动音效由客户端 `audio_engine` 使用 WebAudio 程序化生成；这些 WAV 文件作为静态兼容资源保留。

| 文件 | 时长 | 用途 |
| --- | --- | --- |
| `pop.wav` | 0.18 秒 | 表情提示、语音不可用时的提示 |
| `chime.wav` | 0.65 秒 | 点赞、庆祝、用户主动启用声音 |
| `tomato.wav` | 0.30 秒 | 番茄互动 |

完整事件清单位于 `shared/soundboard.ts`。所有 12 个表情和 10 条中文短句均使用稳定 ID；`duration` 是文字气泡显示的毫秒数。

`voices/` 下的 10 个 MP3 是使用 `edge-tts==7.3.1` 通过 Microsoft Edge 在线神经语音服务生成的合成语音：使用 `zh-CN-XiaoxiaoNeural`、`zh-CN-XiaoyiNeural` 和 `zh-CN-YunxiNeural`，并为不同情绪设置轻微的语速、音高和标点变化。它们是合成语音，不是演员录音，不克隆任何真实人物，也不包含第三方游戏台词。MP3 已随项目保存，运行游戏不需要网络服务或 API。生成脚本和每条短句的参数位于 `scripts/generate-voices.py`；重新生成需要网络连接和 `py -3 -m pip install edge-tts==7.3.1`。

中文短句的 `audioPath` 指向这些本地 MP3。客户端优先播放本地素材；如果本地语音播放失败，则回退到音乐提示音，不使用浏览器 `speechSynthesis`。声音默认关闭；用户开启声音后，轻声模式会降低音量，每次播放新的语音都会立即取消上一段。

声音默认关闭，用户点击“开启声音”后播放试听提示；设置支持静音、音量和轻声模式。轻声模式将语音改为低音量提示音。每次语音会取消上一段，避免多人的短句无限排队。所有互动即使静音也显示文字气泡。
