# 番茄牌局声音资源

本目录的三个 WAV 提示音均为本项目原创、以数学波形合成的单声道 PCM 声音，不包含录音、采样、模仿声音或第三方素材，可随本项目自由使用和修改。

| 文件 | 时长 | 用途 |
| --- | --- | --- |
| `pop.wav` | 0.18 秒 | 表情提示、语音不可用时的提示 |
| `chime.wav` | 0.65 秒 | 点赞、庆祝、用户主动启用声音 |
| `tomato.wav` | 0.30 秒 | 番茄互动 |

完整事件清单位于 `shared/soundboard.ts`。所有 12 个表情和 10 条中文短句均使用稳定 ID；`duration` 是文字气泡显示的毫秒数。

中文短句默认 `audioPath: null`，由浏览器自带的 `speechSynthesis` 中文语音朗读，不克隆任何人的声音。如果没有合成能力或合成失败，则播放本目录的原创提示音。以后加入明确获授权的语音素材时，将对应 `audioPath` 改为本地文件路径；客户端优先播放该素材，失败后才降级至中文朗读。

声音默认关闭，用户点击“开启声音”后播放试听提示；设置支持静音、音量和轻声模式。轻声模式将语音改为低音量提示音。每次语音会取消上一段，避免多人的短句无限排队。所有互动即使静音也显示文字气泡。
